# 지비스 모바일

지비스(PC) **김진호 선생님 한 분 전용** 폰 앱(PWA). 혜원이지 모바일(`hyewon_mobile`)과 주소·열쇠·자료가 따로다.

- 홈 · 시간표 · 출결 · 급식 · 학사일정 · 주간업무 · 문자 문구 · 바로가기 · 이름 외우기
- 자료는 **지비스 허브**(비공개 GAS)에서만 받는다. 허브 주소·열쇠는 이 저장소에 없다 — PC 지비스가 만든 «연결 링크»로 폰마다 한 번 연결한다.
- 앱을 열 때 지문(또는 숫자 6자리)으로 확인한다. 하단 메뉴는 4칸 + 더보기(꾹 눌러 끌어서 바꿈).
- 학생 사진은 이 저장소에 없다(폰 안 IndexedDB 에만 저장).
- `index.html` 은 손으로 고치지 않는다 — 조립 도구(`_tools/jivis-mobile-build`, OneDrive 작업폴더)로 만든다.
